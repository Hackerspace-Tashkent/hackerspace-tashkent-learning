# Hackerspace Tashkent — Обучение

Бесплатные практические материалы по Linux и свободному ПО. Каждая практика выполняется в браузере — ничего ставить не нужно.

## Языки

Русский · English · O'zbek (Latin) · O'zbek (Kirill)

## Начните отсюда

- [Трек Level 0 — с нуля](tracks/level-0/ru.md)
- [Как выполнять практику в Codespace](docs/codespaces/ru.md)
- [Проекты](projects/ru.md)

## Что внутри

- `tracks/` — уроки, разбитые по уровням
- `labs/` — практические задания с автопроверкой
- `projects/` — что делать после уроков
- `docs/` — как работать с материалами

## Как участвовать

Чтобы добавить урок, создай папку в `tracks/level-0/`, напиши его на всех четырёх языках (`en.md`, `ru.md`, `uz-lat.md`, `uz-cyr.md`), добавь практику с её `check.sh` и открой pull request. Примеры кода одинаковы во всех языках — переводится только текст вокруг них.
