# Лойиҳалар

0-даражадан кейин ўз нарсангизни қила оласиз. Кичикдан бошланг, ишлайдиган қилиб тугатинг ва чатда кўрсатинг.

- Танлаган саволга жавоб берувчи Telegram боти.
- Есликларни тартибда ушлаб турувчи скрипт.
- GitHub Пагес да нашр етилган кичик сайт.
- Сизда ҳақиқатан бор масалани ҳал қилувчи буйруқ қатори воситаси.

> **Изоҳ.** 1 ва 2-даражалар ишлаб турибди. Уларда Bash, жарайонлар, тармоқ, Docker ва ЦИ бўлади.
