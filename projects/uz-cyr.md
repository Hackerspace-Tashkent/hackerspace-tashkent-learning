# Лойиҳалар

0-даражадан кейин ўз нарсасингизни қила оласиз. Кичикдан бошланг, ишлайдиган қилиб тугатинг ва pull request очинг.

- Еслакларни тартибда ушлаб турувчи скрипт.
- Сизда ҳақиқатан бор масалани ҳал қилувчи буйруқ қатори воситаси.
- GitHub Pages да нашр этилган кичик сайт.
- Компьютерингиздаги нимани кузатиб, ҳисобот ёзувчи восита.

> **Изоҳ.** 1 ва 2-даражалар ишлаб турибди. Уларда Bash, жарайонлар, тармоқ, Docker ва ЦИ бўлади.
