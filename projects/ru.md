# Проекты

После Level 0 можно делать что-то своё. Начни с малого, доведи до рабочего и открой pull request.

- Скрипт, который держит заметки в порядке.
- Утилита командной строки для задачи, которая у тебя реально есть.
- Небольшой сайт, опубликованный на GitHub Pages.
- Инструмент, который следит за чем-то на компьютере и пишет отчёт.

> **Заметка.** Уровни 1 и 2 в работе. В них будут Bash, процессы, сеть, Docker и CI.
