# 5-дарс. Bash скриптлари

Буйруқларни қўлда ишга туширдингиз. Скрипт буйруқлар кетма-кетлигини сақлайди, шунда қайта йозмасдан йана ишга туширасиз.

```bash
#!/usr/bin/env bash
# Описание: что делает скрипт
echo "Hello from a script"
```

## Ўзгарувчилар

Ўзгарувчи — қиймат учун ном. Типлар йўқ, қўштирноқлар еса қиймат битта бўлак қоладими йоки сўзларга бўлинадими.

```bash
name="Tashkent"
count=3
file="my notes.txt"

echo "$name"      # Tashkent
echo $name        # то же самое, но кавычки безопаснее
echo "$file"      # my notes.txt — один аргумент
echo $file        # my и notes.txt — два аргумента
```

> **Изоҳ.** Ўзгарувчиларни ҳар доим қўштирноқ ичида олинг: "$вар". Акс ҳолда бўшлиқларда бўлинади.

## Шартлар

```bash
if [ -f /etc/hostname ]; then
  echo "file exists"
elif [ -d /etc ]; then
  echo "directory exists"
else
  echo "neither"
fi
```

- `-f` файл мавжуд
- `-d` каталог мавжуд
- `-e` умуман мавжуд
- `-s` файл бўш емас
- `-z` қатор бўш
- `-n` қатор бўш емас
- `=` қаторлар тенг
- `-gt` `-lt` катта / кичик

## Цикллар

```bash
for f in *.txt; do
  echo "found: $f"
done

n=0
while [ "$n" -lt 3 ]; do
  echo "round $n"
  n=$((n + 1))
done
```

## Функсийалар ва аргументлар

Скрипт аргументларни `$1`, `$2` ва ҳокозиларда олади. `$#` — сони, `"$@"` — ҳаммаси, `shift` — биринчисини олиб ташлайди.

```bash
#!/usr/bin/env bash
if [ "$#" -lt 1 ]; then
  echo "usage: $0 <name> [age]" >&2
  exit 1
fi

name="$1"
age="${2:-unknown}"

echo "name=$name"
echo "age=$age"
```

## Чиқим кодлари

Ҳар бир буйруқ рақам билан тугайди: 0 — муваффақият, бошқаси — хато. `$?` охирги буйруқ кодини сақлайди.

```bash
set -e   # остановиться при первой ошибке
set -u   # считать ошибкой неопределённую переменную
set -o pipefail   # ошибка в пайпе, если кто-то в нём упал
```

> **Изоҳ.** `set -e` нинг ўткир бурчаклари бор: `if` ичида, манфий шартда ва қувурнинг охирги буйруғидан ташқарида ишламайди.
