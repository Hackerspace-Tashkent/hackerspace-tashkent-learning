# HTTP API: ўз серверингиз ва унга мижоз

## API нима

**Кодини ўқимасдан** маълумот сўраши мумкин бўлган дастур.

Ҳаво сенсори рақамларни файлга ёзади. Дастур сўрайди: «ҳозир қанча?» —
ва JSON олади. Дастурга рақамлар қаердан келгани муҳим эмас: файлдан,
сенсордан, базадан. Мана шу API: «шунақай сўра, шунақай жавоб бер»
келишуви.

## Сўровнинг анатомияси

Сўров — бу усул, йўл, сарлавҳалар ва баъзан тана.

| Усул | Нимани англатади |
|---|---|
| `GET` | сўраш, ҳеч нарсани ўзгартирмасдан |
| `POST` | янгисини юбориш |
| `PUT` | бутунлай алмаштириш |
| `DELETE` | ўчириш |

```bash
curl http://127.0.0.1:8000/readings
curl -X POST -H "Content-Type: application/json" \
     -d '{"pm25": 42.3}' http://127.0.0.1:8000/readings
```

## Жавоб коди — инсон асосан шуни ўқийди

| Код | Нимани англатади | Кимнинг хатоси |
|---|---|---|
| `200` | ҳаммаси жойида | — |
| `201` | яратилди | — |
| `400` | сўров нотўғри | мижоз |
| `401` | ҳуқуқ йўқ | мижоз |
| `404` | топилмади | мижоз |
| `500` | сервер бузилди | **сервер** |

**Соатлар тежайдиган қоида: 500 — сервер хатоси.** Сервер йиқилиб туриб
турган ҳолда мижозни тузатиш беҳуда. Аввал сервер чиқиши, кейин мижоз.

## JSON

Бундай жавоблар учун одатий формат:

```json
{"time": "2026-10-01T12:00:00", "pm25": 42.3}
```

Рақамлар, сатрлар, `true`/`false`, массивлар ва ички объектлар бор. Ҳаммаси шу.

## Фреймворксиз ўз серверингиз

Codespaces да **flask ҳам, requests ҳам йўқ**, ва бу яхшироқ: протоколни
ўзингиз кўрасиз, фреймворк одатларини эмас. Керакли ҳаммаси стандарт
кутубхонасида бор.

`lab-work/api.py` яратинг:

```python
#!/usr/bin/env python3
import json
import os
from http.server import BaseHTTPRequestHandler, HTTPServer

DATA_FILE = "data.json"


def load():
    try:
        with open(DATA_FILE, encoding="utf-8") as f:
            return json.load(f)
    except (OSError, ValueError):
        return []


class Handler(BaseHTTPRequestHandler):
    def reply(self, code, payload):
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        self.send_response(code)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        if self.path == "/health":
            return self.reply(200, {"ok": True})
        if self.path == "/readings":
            return self.reply(200, load())
        self.reply(404, {"error": "not found"})


HTTPServer(("127.0.0.1", 8000), Handler).serve_forever()
```

Ва маълумот файли `lab-work/data.json`:

```json
[
  {"time": "2026-10-01T12:00:00", "pm25": 42.3},
  {"time": "2026-10-01T12:05:00", "pm25": 39.8}
]
```

Ишга туширинг ва ўзингиздан сўранг:

```bash
cd lab-work
python3 api.py &
curl -s http://127.0.0.1:8000/health
curl -s http://127.0.0.1:8000/readings
curl -s -i http://127.0.0.1:8000/nope
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8000/nope
```

Тўхтатиш: `Ctrl+C`.

## Нега `127.0.0.1` ва `0.0.0.0` эмас

`0.0.0.0` — «барча интерфейсларда эшит» дегани, яъни сервер тармоқдаги
бошқа машиналарга кўринади. Ўқув вазифаси учун бу кераксиз ва хавфсиз
эмас. `127.0.0.1` — фақат сизнинг машинангиз. Ташқарига чиқариш —
қасддан.

## Нега маълумот кода эмас, файлда

**Серверни тўхтатмаб синов қилиш** учун. `data.json` ни ўзгартирдингиз
— жавоб дарҳол ўзгарди. Ҳаммаси кода бўлса, ҳар бир синов учун
қайта ишга тушириш керак, ва беш дақиқадан кейин синовни ташлайсиз.

## Калитлар: нега кода эмас

**Мижоз кодидаги калит — эълон қилинган калит.** Айниқса Pages да:
саҳифа манзилини ким очса, уни кўради. Махфий нарсалар серверда туради,
фойдаланувчи юклаб оладиган нарсада эмас.

## 500 чиқса нима қилиш керак

1. Сервер чиқишини очинг — ҳақиқат у ерда, мижоз хабарида эмас.
2. Кўп учраган сабаб: сўров танасида нотўғри JSON.
3. Иккинчи сабаб: сервер қўллайдиган йўл, лекин мижоз 200 кутади.

## Хулоса

Сервер — бу портда эшитадиган ва HTTP билан гаплашадиган дастур.
`curl` — энг оддий мижоз, ва текшириш учун етарли. Асосий кўникма —
**жавоб кодини ўқиш**, тахмин қилиш эмас.
