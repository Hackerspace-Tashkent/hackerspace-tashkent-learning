# 8-дарс. Тармоқ

Сервер — бу шунчаки портда тинглайотган дастур. Уни ишга тушириб, унга мурожаат қила бошлаганингизда, тармоқ верйондан чиқади.

## Манзиллар ва портлар

```bash
ip addr              # адреса всех интерфейсов
ip route             # куда идёт трафик
hostname -I          # свой адрес
ss -tlnp             # кто слушает порты
```

`127.0.0.1` — бу `localhost`, ўзингиз билан гаплашиш. Порт — 1 дан 65535 гача рақам, тингловчилар орасидан битта дастурни танлайди.

## Серверни ишга тушириш

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

1024 дан катта порт танланг — ундан кичиси роот талаб қилади. `--bind 127.0.0.1` серверини фақат шу машинада очиб қолдиради, бу хавфсиз стандарт.

## Серверга мурожаат

```bash
curl -I http://127.0.0.1:8000     # только заголовки
curl -s http://127.0.0.1:8000 | head    # первые строки
curl -o page.html http://127.0.0.1:8000 # сохранить в файл
echo $?                                # код: 0 — связь есть
```

- `200` ОК
- `301` йоки `302` йўналтирилган
- `404` топилмади
- `403` тақиқланган
- `000` уланиш муваффақийациз

## Манзиллар ўрнига номлар

Хост — манзилга ишора қилувчи ном. `/etc/hosts` кичик маҳаллий рўйхат, ДНС сўралишидан олдин текширилади.

```bash
echo "127.0.0.1  mysite.local" | sudo tee -a /etc/hosts
curl -I http://mysite.local:8000
```

## Агар `ip` ва `ss` топилмади

`ip` ва `ss` буйруқлари `iproute2` пакетида яшайди. Codespaces нинг
баъзи қурилишларида йўқ, ва сиз шуни кўрасиз:

```bash
ip: command not found
```

Бу дарс бузилгани эмас. Йўл бор:

```bash
hostname -I          # ўз манзилингиз — доим бор
cat /proc/net/tcp    # очиқ портлар — ҳам доим бор
```

`/proc/net/tcp` чиқишини ўқиш `ss` дан қийинроқ, шунинг учун машқ
`hostname -I` да қолади. Йўқ бўлса, ўрнатиш учун:

```bash
sudo apt-get install -y iproute2
```

## Амалиёт

1. `lab-work` каталогини йаратинг ва унга ихтийорий матнли `index.html` файлини қўйинг.
2. `serve.sh` йозинг: `python3 -m http.server` ни 8000-портда фонда ишга туширади ва ПИД ни `server.pid` га йозади.
3. Уни ишга туширинг, кейин жавоб кодини `status.txt` га сақланг: `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8000 > status.txt`.
4. `ss -tlnp` (йоки `netstat -tlnp`) чиқишида порт борлигини тасдиқланг ва шу қаторни `ports.txt` га сақланг.
5. `check_site.sh` йозинг: берилган портни сўрайди ва фақат ҳолат 200 бўлганда 0, акс ҳолда 1 билан чиқади. Нотўғри портда 1 бериши керак.
6. `server.pid` даги ПИД билан `kill` қилиб серверни тўхтатинг ва 8000-портда енди ҳеч ким тингламайотганини текширинг.

```bash
cd labs/level-1/04-networking
./check.sh
```
