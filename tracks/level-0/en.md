# Track Level 0 — from zero

Four lessons, one practice each. Everything runs in a Codespace in the browser.

- [Lesson 1. Terminal and navigation](01-terminal/en.md) — `pwd`, `ls`, `cd`, `mkdir`, pipes, `find`, `grep`
- [Lesson 2. Files and permissions](02-files-and-permissions/en.md) — `ls -l`, `chmod`, `chown`, `tar`
- [Lesson 3. Git from scratch](03-git-basics/en.md) — `init`, `add`, `commit`, branches, `.gitignore`
- [Lesson 4. Your first script](04-first-script/en.md) — variables, loops, files, arguments

## How a practice works

1. Read the lesson.
2. Open the practice folder in a Codespace.
3. Do the tasks. You can look things up — that is normal.
4. Run `./check.sh` until it reports all tasks done.
