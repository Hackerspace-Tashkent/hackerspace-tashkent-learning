# Трек Level 0 — с нуля

Четыре урока и практика к каждому. Всё выполняется в Codespace прямо в браузере.

- [Урок 1. Терминал и навигация](01-terminal/ru.md) — `pwd`, `ls`, `cd`, `mkdir`, пайпы, `find`, `grep`
- [Урок 2. Файлы и права доступа](02-files-and-permissions/ru.md) — `ls -l`, `chmod`, `chown`, `tar`
- [Урок 3. Git с нуля](03-git-basics/ru.md) — `init`, `add`, `commit`, ветки, `.gitignore`
- [Урок 4. Первый скрипт](04-first-script/ru.md) — переменные, циклы, файлы, аргументы

## Как проходит практика

1. Прочитай урок.
2. Открой папку практики в Codespace.
3. Выполни задания. Можно подглядывать — это нормально.
4. Запускай `./check.sh`, пока он не покажет, что все задания выполнены.
