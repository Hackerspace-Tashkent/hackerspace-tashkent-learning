# 2-дарс. Файллар ва рухсатлар

Linuxда дастурлар ва ҳужжатлар учун алоҳида папкалар йўқ. Ҳаммаси файл, ва ҳар бир файлда рухсат бор.

## Рухсатларни ўқиш

`ls -l` егаси, гуруҳини ва учта рухсат гуруҳини кўрсатади: `rwx` — егаси, гуруҳ, бошқалар. `r` — ўқиш, `w` — йозиш, `x` — бажариш.

```bash
ls -l
-rw-r--r--  1 user user  2048 Sep 30 10:00 notes.txt
```

## Рухсатларни ўзгартириш

`chmod` рухсатларни ўзгартиради. Рақамларни йотириш осон: 4 — ўқиш, 2 — йозиш, 1 — бажариш.

```bash
chmod 644 notes.txt   # rw-r--r-- : обычный файл
chmod 755 script.sh  # rwxr-xr-x : скрипт
chmod +x script.sh   # просто иҳроқ қилиш
```

`chown` егасини ўзгартиради. Ўз файлларингиз гуруҳини `chgrp` билан ўзгартирасиз.

```bash
chgrp developers notes.txt
```

## Архивлар

```bash
tar -czf backup.tar.gz my-project/
tar -tzf backup.tar.gz
tar -xzf backup.tar.gz
```

## Оддий муҳаррир

`nano` — терминалдаги матн муҳаррири. Цтрл+О сақлайди, Цтрл+Х чиқади.

```bash
nano notes.txt
```

## Скрипт нима

Скрипт — бу оддий матн файли, ичида буйруқлар. `.sh` кенгайтмаси
ўз-ўзидан ҳеч нарса қилмайди: Linux биринчи қаторга қарайди.

```bash
#!/bin/bash
echo " Салом, бу менинг биринчи скриптим"
```

Биринчи қатор **shebang** деб аталади. У тизимга қайси интерпреторни
ишга тушириш кераклигини айтади. У ўзи бажарилмайди — бу йўналиш.

`hello.sh` яратинг, ичига шу икки қаторни ёзинг, кейин:

```bash
chmod +x hello.sh
./hello.sh
```

`chmod +x` бўлмаса «Permission denied» чиқади: тизим файлни ишга
тушириш мумкин бўлган дастур деб ҳисобламайди.

> **Изоҳ.** Скриптни тўғридан-тўғри ишга тушириш учун бажариш рухсати керак: `chmod +x script.sh`.
