# Урок 2. Файлы и права доступа

В Linux нет отдельных папок для программ и документов. Всё — файл, и у каждого файла есть права.

## Чтение прав

`ls -l` показывает владельца, группу и три тройки прав: `rwx` для владельца, группы и остальных. `r` — чтение, `w` — запись, `x` — запуск.

```bash
ls -l
-rw-r--r--  1 user user  2048 Sep 30 10:00 notes.txt
```

## Изменение прав

`chmod` меняет права. Цифры проще запомнить: 4 — чтение, 2 — запись, 1 — запуск.

```bash
chmod 644 notes.txt   # rw-r--r-- : обычный файл
chmod 755 script.sh  # rwxr-xr-x : скрипт
chmod +x script.sh   # просто сделать исполняемым
```

`chown` меняет владельца. Группу своих файлов можно сменить через `chgrp`.

```bash
chgrp developers notes.txt
```

## Архивы

```bash
tar -czf backup.tar.gz my-project/
tar -tzf backup.tar.gz
tar -xzf backup.tar.gz
```

## Простой редактор

`nano` — текстовый редактор в терминале. Ctrl+O сохраняет, Ctrl+X выходит.

```bash
nano notes.txt
```

> **Заметка.** Чтобы запустить скрипт напрямую, нужен бит выполнения: `chmod +x script.sh`.
