# 0-daraja — noldan boshlash

To'rtta dars, har biriga amaliyot. Hammasi brauzerdagi Codespace'da bajariladi.

- [1-dars. Terminal va navigatsiya](01-terminal/uz-lat.md) — `pwd`, `ls`, `cd`, `mkdir`, quvurlar, `find`, `grep`
- [2-dars. Fayllar va ruxsatlar](02-files-and-permissions/uz-lat.md) — `ls -l`, `chmod`, `chown`, `tar`
- [3-dars. Git dan boshlash](03-git-basics/uz-lat.md) — `init`, `add`, `commit`, tarmoqlar, `.gitignore`
- [4-dars. Birinchi skript](04-first-script/uz-lat.md) — o'zgaruvchilar, tsikllar, fayllar, argumentlar

## Amaliyot qanday oʻtadi

1. Darsni o'qing.
2. Amaliyot papkasini Codespace'da oching.
3. Vazifalarni bajaring. Qidirib ko'rsangiz bo'ladi — bu normal.
4. `./check.sh` ni barcha vazifalar bajarilgandacha ishga tushiring.
