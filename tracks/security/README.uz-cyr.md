# Йўналиш: хавфсизлик

Тўртта даража. Бошга трек билан бир хил қоидалар: тўрт тил, ҳеч нарса ўрнатмайди, текширув скрипти, машқ фақат ўз қурилмангиз ва ўз тармоғингизда.

## Бу трекнинг ўзига хослиги

Оддий лаборатория «ишлади ёки йўқ» деб сўрайди. Бу ерда бундай
бўлмайди: ҳеч нарсани тушунмаган одам жавотга қараб яшил олади.
Шунинг учун бу ерда **тушуниш далоли** талаб қилинади: белги эмас,
фақат тушуниб чиққандан кейин олиб бўладиган аниқ қиймат.

## Музокараликка қабул қилинмайдиган қоида

Ҳамма нарса ўз қурилмангизда ва ўз тармоғингизда бўлади. Ўз
серверларингиз `127.0.0.1` да, ўз файлларингиз, ўз тақлидларингиз.
Бошқаларнинг сайти ёки хизмати — «фақат кўриб чиқиш» учун ҳам
йўқ. Бу шаклий эмас: бегона серверга қўл узатиш ўрганишдан
жиноятга айланади.

Сен сарлавҳалар юборасиз. Server уларга ишонади. Демак, ўзингиз
ҳақингизда айтганинг ҳеч нарсани тасдиқламайди. Қолган ҳаммаси шу
асос устида туради.

### S1. Давом этувчи

Аутентификация, кириш назорати, код ичидаги калитлар.

- парол ва токенлар: улар қаерда бўлиши ва қаерда бўлмаслиги керак
- кириш назорати: нега «ўз саҳифамда текширдим» «сеннинг саҳифангизда
  текширдим» дегани эмас
- репозиторий ва браузердаги калитлар: нега саҳифадаги калит энди сизники эмас
- 08-дарсдаги API ни заифликлар бўйича бўлакларга ажратиш


**Ёзилган ва текширилган:**

- [SQL инъекцияси](level-1/01-sql-injection/uz-cyr.md)
- [XSS: код бошқа браузерда бажарилади](level-1/02-cross-site-scripting/uz-cyr.md)

### S2. Илғор

Вебдаги классик заифликлар, ҳар бири ўз локал серверида.

- SQL инъекцияси
- XSS
- йўлни айланиб ўтиш (`path traversal`)
- SSRF
- буйруқ инъекцияси

### S3. Мутахассис

- бинар файллар қандай ишлайди ва буфер тўшиб кетиш нима
- тескари ишлаб чиқариш
- криптография асослари: хеш, туз, нимани тескари қилиб бўлмайди
- тармоқ: трафикни қандай кузатиш

## Нима учун ишонтирилган номлар

Бу трекдаги машқларда **мавжуд бўлмаган** ном ва форматлар ишлатилади:
сарлавҳалар, калитлар, маълумот форматлари. Бу атайлаб қилинган.

Агар вазифа интернетда топилса ёки сунъий интеллектга сўралса, у
ўргатмайди — у эслатгани ўргатади. Мавжуд бўлмаган ном билан
жавобга фақат тушуниб бориш орқали етиш мумкин.

## Иш тартиби

1. Дарс ғояни тушунтиради.
2. Унинг ичида сиз бузадиган нарсани яссайсиз.
3. Лаборатория сизнинг серверингизни ишга тушириб, натижани ҳақиқий
   сўров билан текширади.
4. Белгилар ўрнига **далол** талаб қилинади — аниқ қиймат.

## Ҳали йўқ бўлганлар

Ёзилган ва текширилган: S0 даражаси — **тўртта мавзу**, S1 — **битта**.

Ёзилмаган: S1, S2, S3. Сабаб қийинлик эмас, балки шуки **бирта одам
ҳатто S0 ни ҳам ўтмаган**. Биринчи мавзу ишлашини кўрсатиш керак,
кейин кейинги қават қурилади.
