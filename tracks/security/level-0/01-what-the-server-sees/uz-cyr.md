# Сервер нимани кўради

## Буни нега билиш керак

Сўров юборганда сен **ўйлагандан кўра кўп** нарса юборасиз.
Сен ёзганингдан ташқарида у ерда браузер номи, версия, баъзан тил,
баъзан қаердан келгани маълумотлари бор.

Сервер буларнинг ҳаммасини кўради. **Ва уларга ишонади.**

Бундан келиб чиқадиган нарса янги бошловчиларни чалғитади:
**клиентдан келган «мен ким эканим» ҳақидаги ҳар қандай даъво исбот
эмас.**

## Сўровнинг уч қисми

```text
GET /readings HTTP/1.1
Host: 127.0.0.1:8000
X-Debug: 1
X-Access-Key: sable-marmalade
```

- **усул** — нимани қилмоқчисиз;
- **йўл** — нимага;
- **сарлавҳалар** — қолган ҳаммаси. Ва уларни сохталаш осон.

Сарлавҳа — бу оддий «исм: қиймат» жуфтлиги. Ўзинигизча ёзишни ҳар қандай
`curl` билан мумкин, браузер керак эмас.

## Нима қурасиз

`127.0.0.1:8000` да шундай сервер:

- `/health` — ҳар доим жавоб беради, лекин **агар `X-Debug: 1`
  сарлавҳаси юборилса, ички калитни берib юборади**. Ҳақиқий тизим
  буни атайлаб қилмасди: бу хатолик — тузатиш иш йўқилганда бўлади;
- `/readings` — маълумотни беради, **лекин фақат тўғри
  `X-Access-Key` билан**;
- калитсиз — `403`.

`lab-work/srv.py` яратинг:

```python
#!/usr/bin/env python3
"""Сервер-заглушка. У сарлавҳаларга ишонади -- шу ҳам муаммо."""
import json
from http.server import BaseHTTPRequestHandler, HTTPServer

# Хоёлган ном: интернетда бундай йўқ, калитни қидириб бўлмайди.
ACCESS_KEY = "sable-marmalade-4710"
DATA = [{"time": "12:00", "pm25": 42.3}, {"time": "12:05", "pm25": 39.8}]


class Handler(BaseHTTPRequestHandler):
    def reply(self, code, payload):
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        self.send_response(code)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        # Сарлавҳани мижоз юборди. Сервер уни ишонади.
        # Ҳақиқий тизимда бундай бўлмаслиги керак.
        if self.headers.get("X-Debug") == "1":
            return self.reply(200, {"status": "ok", "debug_key": ACCESS_KEY})

        if self.path == "/readings":
            if self.headers.get("X-Access-Key") == ACCESS_KEY:
                return self.reply(200, {"readings": DATA})
            return self.reply(403, {"error": "key required"})

        self.reply(404, {"error": "not found"})


HTTPServer(("127.0.0.1", 8000), Handler).serve_forever()
```

## Иш тартиби

1. Алоҳида терминалда `python3 srv.py` ишга туширинг.
2. Ҳеч нарсасиз сўранг:

```bash
curl -s http://127.0.0.1:8000/health
```

3. Тузатиш сарлавҳаси билан сўранг:

```bash
curl -s -H 'X-Debug: 1' http://127.0.0.1:8000/health
```

4. У ердан қийматни олиб, маълумотни очинг:

```bash
curl -s -H 'X-Access-Key: <қиймат>' http://127.0.0.1:8000/readings
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:8000/readings
```

Калитсиз `403` қайтади.

5. `notes.md` да жавоб беринг: **сервер нега умуман калитни берди?**

## Далил, белги эмас

`proof.txt` да **топилган калитнинг хешини** ёзинг: sha256 унинг
биринчи 12 белгисидан, кичик ҳарфларда.

```bash
printf '%s' 'kalit' | sha256sum | cut -c1-12 > proof.txt
```

Текширув калитни ўзи олади, хешлайди ва солиштиради. Кўриб бўладиган
нарса йўқ: у на дарсда, на `check.sh` да бор.

## Бу ҳақиқатан нимага ҳақида

Сен **мавжуд бўлмаган** «ҳимояни» айлаб ўтдинг. Server `X-Debug`
сарлавҳасини фақат ўзи қўяди деб ўйлаган. Лекин уни сўраётган
қўяди.

Кимликни сохталаш, кириш назоратидан ўтиш ва кўплаб нарсалар шу
тамойилга қурилган. Остида битта фикр бор: **клиент ишонч манбаи эмас.**

## Муҳим

Ҳаммаси сизнинг машинангизда, `127.0.0.1` да, ўзингиз ёзган серверда
бўлди. **Фақат шундай қилиниши мумкин.** Худди шу усулни бегона
серверга қўллаш — ўрганиш эмас.
