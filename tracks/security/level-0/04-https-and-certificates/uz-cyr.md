# HTTPS ва сертификатлар

## Бууни нега билиш керак

Сен сайтни очиб, манзил қаторида қулфа белгисини кўрасиз.
Браузер қандай билдики, бу боғланиш ҳақиқатан ўша сайт билан ва
ўртада кимдир турмаяпти?

«Қулфа чизилгани учун» эмас. Қулфа икки ҳолатда ҳам бир хил
чизилади: ҳаммаси жойида бўлганда ҳам, **ва** кимдир канални тутганда
ҳам. Фарқи кўзга кўринмайди. Фарқи шундаки, браузер **текширувни**
бажаради.

## Текширув нимадан иборат

**Сертификат** — очиқ калит кимга тегишли эканини ёзувчи ҳужжат.
Ичида ном бор (`CN`, замонавий сертификатларда эса `SAN`) ва амалдаги
муддат.

**Ишонч занжири.** Якка сертификатнинг ўзи ҳеч нарсани англамайди:
сертификатни ким хоҳласа чиқара олади. Керак бўлгани — сиз ишонадиган
кимса, яъни **сертификат маркази**. У сертификатга имзо қўяди,
сизнинг унинг очиқ калитингиз аллақачон бор, демак имзони текшириш
мумкин.

**Из.** Сертификатда хеш бор — қиска из. У сиз кутилган нарса билан
таққосланади.

## Ўз-ўзидан имзоланган сертификат

Сертификатни ўзингиз чиқаришингиз мумкин — `openssl` уни қила олади.
Ва у ишлайди. Аммо браузер унга **ишонмайди**, чунки уни маълум
марказлардан ҳеч ким имзоламаган. Ўзини марказ деб ҳисоблай олмайди:
акс ҳолда ҳар ким ўзига ҳужжат имзолаб, ҳар ким бўлиб чиқиши мумкин
бўларди.

Бу машқда муаммо йўқ: очиқ калит кимга ишонш кераклигини ўзингиз
ҳал қиласиз — ўз сертификатингизни ишончли қилиб кўрсатасиз.

## Энг муҳим қисм

Pythonʼда текширувни битта қатор билан ўчириш мумкин:

```python
ctx = ssl._create_unverified_context()
```

Шундан кейин **ҳар қандай** сертификатга, соxta бўлса ҳам, уланиш
жимгина ўтади. Шифрлаш ўрнида туради, лекин у томда ким борлиги
маълум эмас. Бу — эшикни маҳкамлаб, тешикдан қарамай қолдириш.

## Сен нима қиласан

1. `localhost` учун ўз-ўзидан имзоланган сертификат чиқар.
2. `server.py` ёз: шу сертификат билан HTTPS беради.
3. `client.py` ёз: **текширув билан** ва текширувсиз уланади.
4. `proof.txt` га сертификат SHA-256 изининг биринчи 16 белгисини ёз.
5. `notes.md` да жавоб бер: **шифрлаш ишлаяпти бўлса,
   текширувсиз сертификатда нимаси нотўғри?**

## Буйруқ

```bash
openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem \
  -days 1 -nodes -subj "/CN=localhost"
```

Бир кун — атайлаб: ўқув сертификат абадий яшамаслиги керак.

## Сертификатни кўриш

```bash
openssl x509 -in cert.pem -noout -text
openssl x509 -in cert.pem -noout -fingerprint -sha256
```

## Вазифа чегараси

Ҳамма нарса `127.0.0.1` да, сизнинг компьютерингизда, сизнинг
сертификатингиз билан бўлади. Бошқаларнинг сайтлари текширилмайди
ва сканланмайди. Бошқа одамнинг сертификатларини текшириш — бу
мавзунинг ўқув мақсади эмас.
