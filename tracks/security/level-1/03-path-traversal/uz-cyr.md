# Ўз папкасингиздан ташқарига чиқиш

## Нима учун билиш керак

Серверга кўпинча айтилади: «`notes.txt` файлини бер». Исм сўровдан
келади. Агар ўрнига `../../etc/passwd` юборилса нима бўлади?

Сервер йўлни қўшади: `public/` + `../../etc/passwd`. Ва у берганини
нима қилмоқчи бўлмаган файлни олади. Бу **path traversal**.

## Нима учун ишлайди

Сервер ўзига осон вазифани деб ўйлайди: «қайси файл сўралди».
Аслида бошқа вазифани ечишда: «бу исмга ишониш керакми».

`notes.txt` ва `../../etc/passwd` фарқи — икки нуқта. Сатрларни
қўшадиган сервер ҳеч нарсани кўрмайди.

## Чиқиши керак бўлгани

**Фақат ўз папкасингиздан** файллар берилиши керак. Учта савол:

1. Сўровдаги исм йўлга қандай киради?
2. Унинг ичида `..` бўлса нима бўлади?
3. `/` билан бошланувчи абсолют йўл бўлса нима бўлади?

## Қандай ёпилади

**Қўшгандан кейин текшириш.** Тўлиқ йўлни қуринг ва у айнан хизмат
қилишмоқчи бўлган папка билан бошланишини текширинг.

```python
full = os.path.realpath(os.path.join(ROOT, name))
if not full.startswith(os.path.realpath(ROOT) + os.sep):
    raise PermissionError("папкадан ташқарига")
```

**Абсолют йўлларни қабул қилмаслик.** `/etc/passwd` каби исм файл
номи бўлиб қолиши керак, йўл эмас.

**Ёмон исмларни рад этиш.** Тақиқланган қисмлар рўйхати (`..`,
`\0`) арзон биринчи чизиқ, лекин ягона эмас.

**Идентификаторни бутунлай алмаштириш.** Энг ишончли йўл: сўров
сатрини йўлга умуман киритмаслик. Рақам сўранг ва ўз рўйхатингиз
дан қидиринг.

## Сен нимага қиласан

Сервер аввал заиф бўлиб туради. Уни айланиб ўтасан, кейин тешикни
ёпасан ва ҳар бир чора нима учун ишлашини тушунтирасан.

## Чегара

Фақат ўз компьютерингиз, фақат `localhost`, фақат фикстура
файллари. Бегона серверлар ва ҳақиқий `/etc/passwd` йўқ.
