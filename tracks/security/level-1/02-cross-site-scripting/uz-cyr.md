# Браузер сервер юборган нарсани бажаради

## Нима учун билиш керак

Олдинги мавзуда биз серверга сўров юбориб, жадвалдаги маълумотни олдик.
Бу ерда тескари: сўров юбормаймиз, биз **код** юборамиз, ва бошқанинг
браузери уни бажаради.

Саҳифа матн эмас, код ҳисобланади. Браузер сатрни олади ва HTML
парсерга сўрайди: бу тегми? Агар тег бўлса — у ўгилади. Шу ҳужум
**XSS** деб аталади.

## Нима қилади сервер

Оддий изоҳлар саҳифаси. Кимдир изоҳ ёзади, сервер сақлайди ва
**ҳаммага** кўрсатади.

Экранлаш ўтса, хавфсиз: `<` `&lt;` га айланади ва браузер белгини
кўрсатади, тег қурмайди.

```python
import html
safe = html.escape(user_input)   # <  →  &lt;
```

## Қаерда бузилади

Фойдаланувчи киритмасини экранламасдан HTML га чиқарувчи қаторлар:

- бутун жавоб танаси;
- `f"<p>{body}</p>"`;
- атрибут қийматига киритиш;
- `<script>` ичига киритиш.

Бундай битта қатор — саҳифага келган ҳар бир меҳмон бошқанинг кодини
бажаради. Администратор эмас, муҳандис эмас: **меҳмон**.

## Юкланма

`<img src=x onerror=alert(1)>`

Ўқиш: `img` теги бузилган `src` билан ҳеч қачон юкланмайди, браузер
хато беради ва `onerror` ни бажаради. Расм ҳам, интернет ҳам керак эмас.

`alert` ичидаги матн муҳим эмас. Муҳим ҳолат шу: **код бажарилди**.

## Сен нима қиласан

Серверни ўзинг ёзадиган бўлади. Уни очиқ қилиб, кейин тешикни
ёпадиган бўлади ва ҳимоя нимага аниқ фарқ қилишини тушунтирадиган.

## Чегара

Фақат ўз компьютерингиз, фақат `localhost`, фақат фикстура маълумотлари.
