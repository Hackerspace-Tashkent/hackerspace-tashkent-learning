# Қаердан бошлаш

Қисқа харита: нимага бор, қаердан бошлаш ва аввалдан нимани билиш керак.
Ёзилган: 1 октябр 2026.

## Бошлаш учун кераги

**Браузер ва интернети бор компьютер. Басқа ҳеч нарса.**

Ўз серверингиз керак эмас, Linux керак эмас, ўрнатиш керак эмас —
ҳаммаси Codespaces да, тўғри браузерда ишлайди.

## Вақт ҳақида ҳалол бўлиб

**Биз қанча вақт кетишини билмаймиз.** Шунинг учун рақам ёзмаймиз.

Рақам ўйлаб топилган бўларди: бу дарсликлардан ўтказган одам ҳали
йўқ, демак бизда битта ҳақиқий ўлчов йўқ. Жонли ўтишлар бўлгач,
шу ерда ҳақиқий баҳолар пайдо бўлади.

Ўйлаб бўлмаган ҳолда айтиш мумкин бўлгани: **бир дарс — бир учрашув**,
тахминан кечки вақт. Сабаби ўлчаганимизда эмас, балки ҳар бир дарснинг
ҳажми битта сессия учун мослаштирилгани. Агар дарс кечки вақтга сиғмаса,
биринчи ўтишда кўринади ва биз уни бўламиз.

## Иккита даража эмас, учта кириш

Материал аввал «даражалар»га бўлинган эди, бу нотўғри эди. Рақамлаш
кўринмаганда ҳам, амалда ҳам йўқ зинапоя ваъда қилган эди: GitHub
дарслари тармоқ ва жараёнлар дарсларини талаб қилмайди. Шунинг учун
киришлар учта, ва ҳар бири ўз мақсади учун.

## Қачон тугагани қандай биласиз

**Лаборатория барча белгиларни беради — бу минимал, тугаш эмас.**

Бир ҳақиқий белги: ўзингиз ёзмаган қаторни нима қилишини тушунтира
оласиз. Агар тушунтира олсангиз — тушунгансиз. Агар фақат яшил, лекин
тушунтира олмасангиз — такрорлагансиз, тушунмагансиз.

## Ҳали йўқ бўлганлар

Кутилмаслиги учун ҳалол рўйхат:

- **HTTP API** — йўналиш сифатида ваъда қилинган, дарс йўқ
- **Embedded ва темир** — ускуна режаси ёзилган, дарслар йўқ
- **MQTT ва IoT** — йўқ
- **Level 2** — ваъда қилинган, ёзилмаган
- **Вақт баҳолари** — биринчи жонли ўтишлардан кейин пайдо бўлади

## Одамлар қаерда тўхтайди

**Биз билмаймиз.** Бу материаллардан ўтказган битта одам йўқ.

Бу заифлик эмас ва яширин камчилик эмас — бу ҳозир биз ўлчайётган
нарса. Биринчи дарсни ўтказган ҳар ким бизга қаерда тушунарли
бўлмаганини айтади, ва биз уни тузатамиз. Шунинг учун бирор нарса
тушунарли бўлмаса — бу топилма, сизнинг хатосингиз эмас. Айтинг.

## Ўқимоқдан кўра қилмоқчи бўлсангиз

Биринчи дарсни очинг ва биринчи буйруқни бажаринг. Қолган ҳаммаси
ундан кейин маъно беради.
