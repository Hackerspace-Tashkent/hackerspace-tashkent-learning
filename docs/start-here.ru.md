# С чего начать и зачем всё это

Эта страница для тех, кто ещё ни разу не открывал терминал. Здесь объясняется,
что такое git, GitHub и Codespace, и почему мы выбрали именно их.

Ничего устанавливать не нужно. Нужен браузер и аккаунт на GitHub.

---

## Что такое git

Git — это программа, которая запоминает историю твоих файлов. Она работает на
твоём компьютере, без интернета и без регистрации.

Ты пишешь код, он не переписывает старый, а запоминает: «в этот момент файл
выглядел так». Получается история, к которой можно вернуться.

Ключевое понятие — **коммит**. Это одна сохранённая точка: «я закончил вот этот
шаг». Сообщение к коммиту объясняет, что изменилось.

Дальше есть **ветка** — копия работы, куда можно экспериментировать, не боясь
сломать основную. Сделал, понравилось — слил обратно. Не понравилось — выбросил
ветку, основная не пострадала.

Всё. Это весь git на уровне, который нужен для начала. Остальное — в уроке 3
трека Level 0.

## Что такое GitHub

Git — программа, GitHub — сайт, где лежат твои репозитории. Разница важная:

- git работает **локально**, история лежит у тебя на диске;
- GitHub хранит **копию в интернете**, чтобы её увидели другие.

Кроме хранения, у GitHub есть то, ради чего мы его выбрали:

| Возможность | Зачем она нам |
|---|---|
| **Репозиторий** | Место, где лежат уроки, практики и код. Одна ссылка — и у тебя весь курс. |
| **История изменений** | Видно, кто что поменял. Случайно сломанное всегда можно вернуть. |
| **Issues** | Список задач и вопросов, видимый всем. Открыл — увидел, что кто-то уже спрашивал. |
| **Pull request** | Изменения сначала показывают, потом обсуждают, и только потом принимают. |
| **Codespaces** | Полноценный Linux в браузере. Не нужно ничего ставить. |
| **Открытый доступ** | Всё в открытом виде. Любой может посмотреть, повторить и улучшить. |

## Почему именно GitHub

Короткий честный ответ: потому что это **бесплатно, настраивается один раз и
не требует от ученика ничего, кроме браузера**.

Подробнее — почему это важно именно здесь:

- **Ноль затрат для новичка.** Не нужен свой ноутбук, не нужна установка Linux,
  не нужны деньги на сервер. Есть компьютер, который открывает страницу, — и всё.
- **Работает на слабом компьютере.** Codespace считает в облаке. На старом
  ноутбуке с 4 ГБ оперативки полноценная среда не запустится, а веб-версия
  откроется.
- **Не привязывает к одному человеку.** Материалы лежат на GitHub, а не в
  переписке и не на чьём-то ноутбуке. Через год они будут доступны, даже если
  автор переедет.
- **Проверка встроена в процесс.** Результат практики — это комментарий в
  публичном issue. Видно, кто прошёл, и это нельзя «подрисовать».
- **Всё на русском, английском и узбекском в одном месте.** Четыре версии каждого
  урока лежат рядом, а не в четырёх разных местах.

Чего мы **не** выбирали и почему:

- **Свой сайт с регистрацией и личными кабинетами** — это сервер, который нужно
  оплачивать, защищать и администрировать. Дорого и некому.
- **Google Docs или Notion** — удобно читать, но нельзя выполнить и проверить
  задание.
- **Видеоуроки** — смотрятся легко, но не проверяются и не оставляют след работы.

## Что такое Codespace

Codespace — это виртуальный компьютер с Linux, который живёт в облаке GitHub и
открывается в браузере. Нажал кнопку — и у тебя открылась настоящая командная
строка.

Что это даёт:

- Всё уже установлено: терминал, git, Python, редактор. Ничего не ставится.
- Работает с любого устройства, где есть браузер. Начал на компьютере —
 продолжил на телефоне.
 - Настройка среды лежит в репозитории, а не в твоей голове. У всех одинаково.
- Среда компактная: 2 ядра и 4 ГБ памяти. Этого хватает на все наши уроки.
- Если что-то сломалось — среда удаляется и создаётся заново за минуту. Дёшево
  экспериментировать.

Ограничение, о котором стоит знать честно: Codespace — это Linux. Если у тебя
Windows и ты хочешь учиться в Windows, часть практик придётся адаптировать.

## Что тебе нужно

Обязательно:

- браузер,
- аккаунт на GitHub,
- около двух часов на первый урок.

Не нужно:

- устанавливать Linux,
- устанавливать что-либо на свой компьютер,
- покупать оборудование для первых пяти уроков,
- знать что либо про программирование заранее,
- уметь работать с git — этому учит урок 3.

## Три шага до первого задания

1. Создай аккаунт на GitHub, если его ещё нет.
2. Открой репозиторий обучения и нажми **Code → Codespaces → Create codespace
   on main**. Через минуту откроется терминал.
3. Открой урок 1 и выполни команды руками. В конце запусти проверку.

Если что-то непонятно — открой issue или спроси в чате. Ошибка в задании
полезнее, чем молчание: она показывает, где именно ты застрял.
