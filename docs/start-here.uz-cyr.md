# Нимадан бошлаш керак ва нима учун ҳамма шу

Бу саҳифа биринчи марта терминал очмаганлар учун. Унда git, GitHub ва Codespace
нима экани, биз нима учун айнан уларни танлагшимиз тушунтирилган.

Ҳеч нарсани ўрнатиш шарт эмас. Керак бўлган фақат браузер ва GitHub ҳисоби.

---

## Git нима

Git — бу дастур. У сизнинг файлларингиз тарихини эслаб қолдиради. У сизнинг
ўз компютерингизда ишлайди, интернетсиз ва рўйхатдан ўтмасдан.

Код ёзганда git эскисини устига ёзмайди — у эслаб қолдиради: «шу вақтда файл
шу тарзда кўринарди». Натижада қайтиб бориш мумкин бўлган тарих ҳосил бўлади.

Асосий тушунча — **commit**. Бу битта сақланган нуқта: «мен шу босқични
тугатдим». Commit хабари эса нима ўзгарганини тушунтиради.

Кейин **branch** келади — бу сизнинг ишингиз нусхаси, унда тажриба қилиб
тузатишни ўз асл нусхасига тегмай туриб синов кўришингиз мумкин. Чиқди,
ёқди — асл нусхага қўшдингиз. Чилмади — branch ни ташлаб юбордингиз, асл
нуша бутунлай жараҳатланмаган.

Ҳаммаси шу. Бошлаш учун зарур даражада бутун git шу. Қолгани Level 0
трекининг 3-дарсида.

## GitHub нима

Git — дастур, GitHub эса сизнинг репозиторийларингиз турган сайт. Фарқ муҳим:

- git **махаллий** ишлайди, тарих сизнинг дискингизда ётади;
- GitHub **интернетдаги нусхани** сақлайди, бошқалар кўра олиши учун.

Сақлашдан ташқари, GitHub бизни рағбатлантирган нарсалар бор:

| Имконият | Биз учун нима учун |
|---|---|
| **Репозиторий** | Дарслар, амалиёт ва код шу ерда. Бита ҳавола — бутун курс қўлда. |
| **Ўзгаришлар тарихи** | Ким нима ўзгартиргани кўринади. Тасодифан бузилгани ҳар доим қайтарилади. |
| **Issues** | Вазифа ва саволлар рўйхати, ҳаммага кўринади. Очсангиз — кимдир аллақачон сўраганини кўрасиз. |
| **Pull request** | Ўзгаришлар аввал кўрсатилади, кейин муҳокама қилинади, кейин қабул қилинади. |
| **Codespaces** | Браузерда тўлиқ Linux. Ҳеч нарса ўрнатиш шарт эмас. |
| **Очиқ кириш** | Ҳаммаси очиқ. Ким хоҳласа кўради, такрорлайди ва яхшилайди. |

## Нима учун айнан GitHub

Қисқа ва ҳалол жавоб: чунки у **бепул, бир марта созланади ва ўқувчидан
фақат браузер талаб қилади**.

Муҳимроқ шу — бу ерда айнан нима учун муҳим:

- **Бошланғич учун нол харажат.** Ўз ноутбукингиз, Linux ўрнатиш ёки
  серверга тўлов керак эмас. Саҳифни очадиган компютер етарли.
- **Заиф компютерда ишлайди.** Codespace булутда ҳисоблайди. 4 GB оператив хотирали
  эски ноутбукда тўлиқ муҳит ишламайди, лекин браузер версияси очилади.
- **Ишни бир кишига боғламайди.** Материаллар чатда эмас, кимнирдинг
  ноутбукида эмас, GitHub'да туради. Бир йилдан кейин ҳам у ерда бўлади,
  муаллиф кўчса ҳам.
- **Текшириш жараёнга қўшилади.** Амалиёт натижаси оммавий issue'даги изоҳ. Ким
  ўтгани кўринади ва бу жим қилиб таҳрирлаб бўлмайди.
- **Тўрт тил, битта жой.** Ҳар бир дарснинг тўртта версияси ёнма-йон туради,
  тўрт хил жойда тарқалган ҳолда эмас.

Биз қандай вариантни ** танлаганмиз** ва нега:

- **Ўз сайтимиз, рўйхатдан ўтиш ва шахсий кабинетлар билан** — бу тўланадиган,
  ҳимояланадиган ва бошқариладиган сервер. Қиммат, ва уни бошқарадиган киши
  йўқ.
- **Google Docs ёки Notion** — ўқиш учун қулай, лекин у ерда топшириқни
  бажариб текшириб бўлмайди.
- **Видео дарслар** — кўриш осон, лекин текширилмайди ва иш изи қолмайди.

## Codespace нима

Codespace — GitHub'нинг булутида яшайдиган, браузерда очиладиган Linux'ли
виртуал компютер. Тугмани босдингиз — ҳақиқий буйруқ қатори очилди.

Бу нима беради:

- Ҳаммаси аллақачон ўрнатилган: terminal, git, Python, муҳаррир. Ҳеч нарса
  ўрнатмайсиз.
- Браузер борган ҳар қандай қурилмада ишлайди. Компютерда бошладингиз —
  телефонда давом эттирдингиз.
- Муҳит сўрови репозиторийда туради, миягингизда эмас. Ҳаммада бир хил.
- Муҳит кичик: 2 ядро ва 4 GB оператив хотира. Барча дарсларимиз учун етади.
- Нимадир бузилса, муҳит ёпилади ва бир дақиқада қайта яратилади. Тажриба қилиш
  арзон.

Ҳалол айтиш керак бўлган чегара: Codespace — бу Linux. Агар сизда Windows
бўлса ва Windows'да ўрганмоқчи бўлсангиз, амалиётнинг бир қисмини мослаштириш
керак бўлади.

## Сизга нима керак

Керак:

- браузер,
- GitHub ҳисоби,
- биринчи дарс учун тахминан икки соат.

Керак эмас:

- Linux ўрнатиш,
- ўз компютерингизга бирор нарса ўрнатиш,
- дастлабки беш дарс учун ускуна сотиб олиш,
- олдиндан дастурлашни билиш,
- git ишлата билиш — буни 3-дарс ўргатади.

## Биринчи топшириқ уч қадам

1. Агар GitHub ҳисобингиз йўқ бўлса, яратинг.
2. Ўрганиш репозиторийни очинг ва **Code → Codespaces → Create codespace
   on main** ни босинг. Бир дақиқада terminal очилади.
3. 1-дарсни очинг ва буйруқларни қўлда бажаринг. Охирида текширувни ишга
   туширинг.

Нимадир тушунарли бўлмаса, issue очинг ёки chatда сўранг. Қотиб қолиш жим
қолишдан фойдалироқ: у айнан қаерда тўхтаганингизни кўрсатади.
