# Как выполнять практику в Codespace

Codespace — это Linux-машина прямо в браузере. Ничего не нужно ставить и нечего сломать.

## Запуск

1. Открой репозиторий на GitHub на ветке `main` — практики лежат в `labs/`.
2. Нажми зелёную кнопку **Code**, затем вкладку **Codespaces**.
3. Выбери размер машины: **2 ядра, 4 ГБ** хватает для всех практик этого трека.
4. Нажми **Create codespace** и подожди около минуты.

## Запуск проверки

```bash
cd labs/level-0/01-terminal
./check.sh
CHECK_LANG=en ./check.sh
```

Каждая строка показывает, выполнено ли задание. Скрипт завершится с кодом 0, когда всё готово.

## Как не тратить много

Codespace считает по часам, и простаивающие продолжают съедать квоту. Репозиторий настроен так, чтобы этого избежать.

- **Маленькая машина.** Devcontainer запрашивает 2 ядра и 4 ГБ — самый дешёвый подходящий размер.
- **Ничего тяжёлого внутри.** Ни рабочего стола, ни сборочных инструментов без нужды.
- **Останавливается при закрытии.** В `devcontainer.json` стоит `shutdownAction: stopContainer`:
  когда ты закрываешь окно Codespaces, машина останавливается сама.
- **Организационные лимиты не настроены.** Остановка через 30 минут простоя и удаление через
  0 дней пока не заданы. Это значит: надёжно полагайся только на ручную остановку.

> **Важно.** Простой Codespace продолжает считаться по квоте. Закрывай его сам:
> в меню **Codespaces** выбери *Stop codespace*. Удаление занимает несколько секунд.
> Если замечаешь, что упираешься в лимит, первым делом закрой лишние машины.

## Если Codespace работает медленно

Практика специально небольшая. При медленной связи не ставьте ничего лишнего и выполняйте задания по порядку — каждое зависит от предыдущего.
