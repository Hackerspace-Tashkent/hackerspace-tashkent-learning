# Амалиётни Codespaceda қандай бажариш керак

Codespace — браузердаги Linux машинаси. Ҳеч нарса ўрнатиш йоки бузиш шарт емас.

## Бошлаш

1. GitHubda репоситорйни очинг ва амалийот бўлган тармоққа ўтинг.
2. Йашил **Цоде** тугмасини, кейин **Codespaces** табини босинг.
3. Машина ҳажмини танланг: **2 йадра, 4 ГБ** бу трекдаги барча амалийотларга йетади.
4. **Яратиш codespace** ни босинг ва тахминан бир дақиқа кутинг.

## Текширувни ишга тушириш

```bash
cd labs/level-0/01-terminal
./check.sh
CHECK_LANG=en ./check.sh
```

Ҳар бир қатор вазифа бажарилганини кўрсатади. Барчаси тугаганда скрипт 0 коди билан чиқади.

## Харажатларни кам ушлаш

Codespace соатига тўланади ва бўш турганлари квотани йейверади. Репозиторий буни олдини олиш учун созланди.

- **Кичик машина.** Devcontainer 2 йадра ва 4 ГБ сўрайди — енг арзон мос ўлчам.
- **Ичида оғир нарса йўқ.** Иш столи йоки қуриш воситалари керак бўлганда.
- **Бўш турган тўхтайди.** Ташкилот созламалари 30 дақиқа фаолсизликдан кейин Codespaceni тўхтатади.
- **Тўхтагандан кейин ўчади.** Сақлаш 0 кунга созланган, шунинг учун тўхтаган Codespace автоматик ўчади.

> **Изоҳ.** Қўлда ҳам тўхтатишингиз мумкин: Codespaces менйусида *Стоп codespace* ни танланг. Ўчириш бир неча сонийа олади.

## Агар Codespace секин ишлайотган бўлса

Амалийот атайлаб кичик. Секин интернетда ортиқча нарса ўрнатманг ва вазифаларни кетма-кет бажаринг — ҳар бири олдингисига боғлиқ.
