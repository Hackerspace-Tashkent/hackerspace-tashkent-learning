Uroq qoʻshish uchun `tracks/level-0/` da papka yarating, uni toʻrt tilda yozing (`en.md`, `ru.md`, `uz-lat.md`, `uz-cyr.md`), amaliyot va uning `check.sh` faylini qoʻshing, soʻng pull request oching. Kod misollari barcha tillarda bir xil qoladi — faqat ular atrofidagi matn tarjima qilinadi.

> **Izoh.** Savollar va gʻoyalar: https://t.me/hackerspace_tashkent_chat — yoki GitHub'da issue oching.
