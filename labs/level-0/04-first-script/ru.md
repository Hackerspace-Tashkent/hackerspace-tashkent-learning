# Урок 4. Первый скрипт

Скрипт — это файл с командами, который выполняется как одна программа. Вместо того чтобы каждый раз набирать одно и то же, сохраняешь один раз и запускаешь всегда.

## Привет, скрипт

Первая строка говорит системе, какой интерпретатор использовать. Дальше Python выводит то, что в кавычках.

```python
#!/usr/bin/env python3
print("Hello, Hackerspace!")
```

Сохрани как `hello.py` и запусти. Сделай исполняемым, чтобы запускать без `python3`.

```bash
chmod +x hello.py
./hello.py
```

## Переменные и условия

```python
name = input("Your name: ")
if name:
    print(f"Nice to meet you, {name}!")
else:
    print("Hello, stranger!")
```

## Циклы

```python
for i in range(1, 6):
    print(f"{i} squared is {i ** 2}")
```

## Работа с файлами

Скрипты становятся полезными, когда работают с файлами. Контекстный менеджер закроет файл сам, даже если что-то пойдёт не так.

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("first line\n")
    f.write("second line\n")
```

Подсчёт строк — классическая первая задача. Именно это требуется в практике.

```python
count = 0
with open("notes.txt", encoding="utf-8") as f:
    for line in f:
        count += 1
print("lines:", count)
```

> **Заметка.** Ошибки — это нормально. Смотри последнюю строку traceback — она обычно прямо говорит, что не так.
