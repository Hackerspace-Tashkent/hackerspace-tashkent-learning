# 6-дарс. Автоматлаштириш ва журналар

Ўзи бажарадиган вазифа — еслаб туриш керак бўлган вазифадан анча қимматли. Бу дарс режимани йоқиш ва из қолдириш ҳақида.

## Чиқим оқимлари

Ҳар бир буйруқнинг учта оқими бор: натижа учун стандарт чиқим, муаммолар учун хато чиқими ва кирим. `>` файл ёзади, `>>` қўшади, `2>` хатоларни йўналтиради.

```bash
ls > out.txt          # только stdout, очистит файл
ls >> out.txt         # добавит в конец
ls 2> err.txt         # только stderr
ls > all.txt 2>&1     # и то и другое в один файл
ls 2>&1 | grep txt    # ошибки тоже попадут в пайп
```

> **Изоҳ.** Журнал — бул файл, унга қўшиб борса, ҳеч қачон тозаланмайди. `>>` ишлатнг ва ҳар қаторнинг бошига сана қўйинг.

```bash
#!/usr/bin/env bash
log="run.log"
printf '%s started\n' "$(date '+%F %T')" >> "$log"
printf '%s finished with code %d\n' "$(date '+%F %T')" "$?" >> "$log"
```

## cron билан режа

`cron` белгиланган вақтда буйруқни ишга туширади. Қаторда бешта майдон бор: дақиқа, соат, ой куни, ой, ҳафта куни, сўнг буйруқ.

```bash
# минута час день месяц день_недели  команда
*/5 *   *   *     *            /home/me/report.sh
0  9   *   *     1-5          /home/me/backup.sh
30 18  *   *     *            /home/me/clean.sh
```

cronга ҳеч қачон почта йубормаслик. Иккала оқимни журнал файлига йўналтиринг.

```bash
*/10 * * * * /home/me/report.sh >> /home/me/report.log 2>&1
```

## Режани таҳрирлаш

```bash
crontab -l     # показать текущие задачи
crontab -e     # изменить
crontab -r     # удалить все (осторожно)
```

Crontab — бу шунчаки матн файл, ҳар сатрда битта вазифа. `crontab myfile` уни ўрнатади, `crontab -l` ўрнатилганини кўрсатади. Режани файлда сақласангиз — йани `crontab -e` ичида кўз йопиб таҳрирлаш ўрнига — уни gitда тутиб, ҳар қандай машинага кўчириш мумкин.

> **Изоҳ.** кодспейсда `cron` даемонси ишламайди, шунинг учун ўрнатилган вазифалар ўз-ўзидан ишга тушмайди. Амалийот файл билан ишлайди: режани йозинг ва файл тўғрилигини текширинг.
