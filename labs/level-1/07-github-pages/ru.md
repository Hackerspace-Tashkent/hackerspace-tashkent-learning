# Практика: GitHub Pages

## Что делать

Всё в `lab-work/` рядом с этим файлом.

```bash
cd "$(dirname check.sh)"
mkdir -p lab-work
cd lab-work
```

### 1. Страница

Создай `index.html`. Минимум, который проверяется:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет</h1>
  <p>Опубликовано из репозитория.</p>
</body>
</html>
```

`lang` важен: без него экранные читалки не поймут, на каком языке текст.
`viewport` — чтобы на телефоне не разъезжалось.

### 2. Проверить локально

```bash
python3 -m http.server 8000
```

Открой `http://127.0.0.1:8000`. Работает — значит код в порядке и дело в
настройках Pages, если не заработает после публикации.

Остановить: `Ctrl+C`.

### 3. Опубликовать — выбери один из двух путей

**Путь A: локально.** Работает без аккаунта GitHub. Оставь сервер
запущенным из предыдущего шага и впиши в `PUBLISHED.md` его адрес:

```
http://127.0.0.1:8000/index.html
```

Проверка сходит туда и убедится, что страница отвечает.

**Путь B: публично.** Нужен аккаунт GitHub. Файл уже в `main`. Теперь
**Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка
`/ (root)`, сохранить. Через минуту-три открой адрес, который покажет
GitHub. Он будет вида `https://твой-логин.github.io/имя-репозитория/`.

**Путь B учит большему, но путь A — полноценная практика.** Без
аккаунта GitHub сдать её можно, и это нормально: аккаунт появится позже.

### 4. Записать

`PUBLISHED.md` — одна строка с рабочим адресом. Именно она проверяется на
ответ 200.

`NOTES.md` — что получилось, что нет, сколько ждал появления.

## Проверка

```bash
./check.sh
```

Десять локальных проверок и, если адрес указан и есть `curl`, одиннадцатая —
живой запрос к твоему сайту.

## Если сайт не открылся

- **404** — имя файла не `index.html`, либо папка не `/ (root)`
- **пустая страница** — файл есть, но пустой или сломан HTML
- **404 на вложенных файлах** — CSS и JS лежат не там, откуда их ищет страница
- **долгое ожидание** — иногда публикация занимает до нескольких минут

## Что практика не проверяет

Она не проверяет вёрстку и не проверяет, красиво ли. Это вкусовое, и
автоматическая проверка его не заменит.
