# Лаборатория: GitHub Pages

## Нима қилиш керак

Ҳамма нарса шу файл ёнидаги `lab-work/` да.

```bash
cd "$(dirname check.sh)"
mkdir -p lab-work
cd lab-work
```

### 1. Саҳифа

`index.html` яратинг. Текшириладиган энг кичик вариант:

```html
<!DOCTYPE html>
<html lang="uz">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Менинг биринчи саҳифам</title>
</head>
<body>
  <h1>Салом</h1>
  <p>Репозиториядан эълон қилинди.</p>
</body>
</html>
```

`lang` муҳим: у бўлмаса экран ўқувчиси матн қайси тилда эканини
тушунмайди. `viewport` — телефонда бузилмаслиги учун.

### 2. Маҳаллий текшириш

```bash
python3 -m http.server 8000
```

`http://127.0.0.1:8000` ни очинг. Ишлаяпти — код тўғри, кейин эълон қилгандан
кейин ишламаса, муаммо Pages созламасида.

`Ctrl+C` билан тўхтатинг.

### 3. Эълон қилиш

Файл аллақачон `main` да. Энди **Settings → Pages → Source: Deploy from a
branch**, тармоқ `main`, папка `/ (root)`, сақланг.

Бир-уч дақиқадан кейин GitHub кўрсатадиган манзилни очинг. У
`https://сизнинг-логин.github.io/репозиторий-номи/` кўринишида бўлади.

### 4. Ёзиб қўйиш

`PUBLISHED.md` — ишлайдиган манзил билан бир қатор. Айнан шу 200 га жавоб
бўлиши текширилади.

`NOTES.md` — нима ишлади, нима ишладимайди, чиқиш қанча вақт олди.

## Текширув

```bash
./check.sh
```

Ўнта маҳаллий текширув ва, агар манзил берилган бўлса ва `curl` бўлса,
ўнинчи — тирик сўров ўзингизнинг сайтингизга.

## Сайт очилмаса

- **404** — файл номи `index.html` эмас, ёки папка `/ (root)` эмас
- **бўш саҳифа** — файл бор, лекин бўш ёки HTML бузилган
- **боғланган файлларда 404** — CSS ва JS саҳифа излаган жойда эмас
- **узун кутиш** — эълон қилиш баъзан бир неча дақиқа олади

## Лаборатория нимани текширмайди

У layoutни текширмайди ва чиройли эканини ҳам текширмайди. Бу — дид, ва
автоматик текширув уни алмаштирмайди.
