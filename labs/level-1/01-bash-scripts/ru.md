# Урок 5. Скрипты на Bash

Ты запускал команды руками. Скрипт сохраняет последовательность команд, чтобы запустить её снова без повторного набора.

```bash
#!/usr/bin/env bash
# Описание: что делает скрипт
echo "Hello from a script"
```

## Переменные

Переменная — имя для значения. Типов нет, а кавычки решают, останется значение одним куском или разобьётся на слова.

```bash
name="Tashkent"
count=3
file="my notes.txt"

echo "$name"      # Tashkent
echo $name        # то же самое, но кавычки безопаснее
echo "$file"      # my notes.txt — один аргумент
echo $file        # my и notes.txt — два аргумента
```

> **Заметка.** Всегда бери переменные в кавычки: "$var". Без кавычек значение развалится на пробелах, а пустое исчезнет.

## Условия

```bash
if [ -f /etc/hostname ]; then
  echo "file exists"
elif [ -d /etc ]; then
  echo "directory exists"
else
  echo "neither"
fi
```

- `-f` файл существует
- `-d` каталог существует
- `-e` существует вообще
- `-s` файл не пустой
- `-z` строка пустая
- `-n` строка не пустая
- `=` строки равны
- `-gt` `-lt` больше / меньше

## Циклы

```bash
for f in *.txt; do
  echo "found: $f"
done

n=0
while [ "$n" -lt 3 ]; do
  echo "round $n"
  n=$((n + 1))
done
```

## Функции и аргументы

Скрипт получает аргументы в `$1`, `$2` и так далее. `$#` — их количество, `"$@"` — все сразу, `shift` — убрать первый.

```bash
#!/usr/bin/env bash
if [ "$#" -lt 1 ]; then
  echo "usage: $0 <name> [age]" >&2
  exit 1
fi

name="$1"
age="${2:-unknown}"

echo "name=$name"
echo "age=$age"
```

## Коды возврата

Любая команда заканчивается числом: 0 — успех, иное — ошибка. `$?` хранит код последней команды.

```bash
set -e   # остановиться при первой ошибке
set -u   # считать ошибкой неопределённую переменную
set -o pipefail   # ошибка в пайпе, если кто-то в нём упал
```

> **Заметка.** У `set -e` есть острые углы: не срабатывает внутри `if`, в отрицании условия и в пайпе, кроме последней команды. Используй в скриптах, но не вслепую в интерактивной оболочке.
