# Дастур: фойдаланувчи ёзган буйруқ

## Нима берилган

`lab-work/` да фикстура яратди:

- `flag.txt` — `flag{ne_privet_iz_komandy}` мазҳунли файл;
- `hosts.txt` — сервер текширадиган хостлар рўйхати.

## Қадамлар

1. Фикстурани тайёрланг:

```bash
bash setup.sh
```

2. Нима пайдо бўлганини кўринг:

```bash
ls lab-work
cat lab-work/hosts.txt
```

3. `srv.py` ёзинг:

- `GET /ping` йўли `host` параметрини олади;
- сервер текширувни ишга туширади ва чиқишни қайтаради;
- `python3 srv.py <port> [--unsafe]` — порт ва ихтиёрий белги;
- **белгисиз** буйруқ аргументлар рўйхати қилиб йиғилади, shell
  ишлатилмайди;
- **`--unsafe` билан** f-string билан сатр йиғилиб, `shell=True`
  билан ишга туширилади — шунда тешик чиқади.

Заиф вариант:

```python
cmd = f"ping -c 1 {host}"
out = subprocess.run(cmd, shell=True, capture_output=True, text=True)
```

4. Заиф серверни ишга туширинг:

```bash
cd lab-work
python3 srv.py 8104 --unsafe
```

5. Оддий сўров:

```bash
curl -G --data-urlencode 'host=localhost' \
  http://127.0.0.1:8104/ping
```

6. Энди инъекция. Хост номига буйруқ қўшинг:

```
curl -G --data-urlencode 'host=; cat flag.txt' \
  http://127.0.0.1:8104/ping
```

Жавобда `flag{...}` чиқса — тешик топилди. `&& cat flag.txt` ва
`$(cat flag.txt)` ни ҳам синаб кўринг: улар бошқа сабаб билан ишлайди.

7. **`flag.txt` ни ўчирманг.** Текширув буни алоҳида кузатади.
8. Энди тешикни ёпинг. f-string ва `shell=True` ни олиб ташланг,
   рўйхат беринг:

```python
out = subprocess.run(["ping", "-c", "1", host],
                     capture_output=True, text=True)
```

9. Белгисиз қайта ишга туширинг ва иккала заҳарли юкламани яна
   юборинг: иккаласи ҳам оддий муваффақиятсизлик қайтармоқчи.

## Текширилади

| | |
|---|---|
| 1 | `srv.py` файли мавжуд |
| 2 | сарвер HTTP орқали жавоб беради |
| 3 | оддий хостга жавоб берилади |
| 4 | юкланган буйруқ `flag.txt` ни ўқийди |
| 5 | ёпилгандан кейин инъекция ишламайди |
| 6 | `flag.txt` ўчирилмаган |

4 ва 5 бир сервернинг икки режимини текширади: аввал `--unsafe` билан,
кейин белгисиз.

## Г чегарасига етиш

«Сатрда `;` йўқ» текшируви етарли кўринади айниқса биринчи уни ювиб
ўтадиган тест-кейсгача. Аргументлар рўйхатини эса ювиб бўлмайди: унга
буйруқ қўшишга жой йўқ. Савол шунинг учун «қайси белгиларни тақиқлаймиз»
эмас, «сўровдан келган сатр қаерда дастурга айланади».
