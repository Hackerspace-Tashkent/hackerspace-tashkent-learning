# Дастур: браузер орқали токенни олиш

## Нима берилган

`lab-work/` ичида аллақачон `reviews.db` базаси бор: учта изоҳ ва `admin`
жадвали, унда токен туради. **Токен саҳифада йўқ** — у `admin.token` да
қолади, изоҳлар саҳифаси эса фақат изоҳларни кўрсатади.

## Қадамлар

1. Фикстура тайёрланг:

```bash
bash setup.sh
```

2. Базада нима борлигини кўринг. Codespaces да `sqlite3` мижози йўқ,
   шунинг учун Python орқали очинг — у ҳар доим мавжуд:

```bash
python3 -c "
import sqlite3
c = sqlite3.connect('lab-work/reviews.db')
print([r[0] for r in c.execute(
    "SELECT name FROM sqlite_master WHERE type='table'")])
print(list(c.execute('SELECT author, body FROM reviews')))
"
```

Токен `admin` жадвалида. У сига фақат **текшириш учун** керак, саҳифага
у кириб келмайди.

3. `srv.py` ёзинг:

- `GET /` — барча изоҳлар саҳифаси;
- `POST /review` — `author` ва `body` қабул қилади, изоҳни сақлайди ва
  саҳифани қайта кўрсатади;
- `python3 srv.py <port>` — порт рақамини аргумент сифатида олади;
- `author` ва `body` ни **экранламасдан** HTML ичига жойлаштиринг —
  шунда юкланма саҳифага етиб боради.

4. Серверни ишга туширинг:

```bash
cd lab-work
python3 srv.py 8102
```

5. Браузерда `http://127.0.0.1:8102/` ни очинг, изоҳ юборинг:
   `<img src=x onerror=alert(1)>`. Саҳифа манбасида тег пайдо бўладими?

6. Энди токенни олинг. У `admin` жадвалида, саҳифа эса фақат `reviews`
   кўрсатади. Демак **сервер ўзи** бошқа жадвални қайтариши керак.

   Эслаб қол: саҳифани браузер очидаги ва сервер юбган нарсани
   бажаради. Шунинг учун `admin` га сўров **сервер томонида**
   бўлиши керак, жавоб эса саҳифа танисига келиши керак.

7. Токен sha256 нинг дастлабки 12 белгисини `lab-work/proof.txt` га ёзинг:

```bash
python3 -c "
import sqlite3, hashlib
t = sqlite3.connect('lab-work/reviews.db').execute(
    'SELECT token FROM admin LIMIT 1').fetchone()[0]
print(hashlib.sha256(t.encode()).hexdigest()[:12])
" > lab-work/proof.txt
```

8. Энди тешикни ёпинг: чиқаришдан олдин `author` ва `body` ни
   экранланг. Юкланма энди матн сифатида келиши керак, тег эмас.

## Текширилади

| | |
|---|---|
| 1 | `srv.py` файли мавжуд |
| 2 | сарвер HTTP орқали жавоб беради |
| 3 | изоҳ киритмаси яна саҳифага қайтади |
| 4 | юкланма матн эмас, тег сифатида келади |
| 5 | `proof.txt` да чиқарган токенинг хеши бор |

3 ва 4-текширувлар **сизнинг** серверингизда ўтади: текширув юкланма
юборади ва жавобга қарайди. Бошқа процессни қабул қилмайди.

## Г чегарасига етиш

HTML экранилаш — бу «`escape` қўшиш» эмас. Бу қарор:

- чиқариш HTML га айнан қаерда бўлади;
- фойдаланувчи киритмасининг ҳаммаси экранланадими;
- бир марта кўп экранланадими (матр нотўғри чиқади);
- киритма атрибутга ёки `<script>` ичига тушадими — у ерда
  `html.escape` етарли эмас.
