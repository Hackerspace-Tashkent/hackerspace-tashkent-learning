Yettinchi — fayl oʻqish emas. Tekshiruv sizning serveringizni ishga
tushiradi, uning bilan HTTP orqali gaplashadi va mavzu nimaga haqida
boʻlgan aniq xilni talab qiladi.

## Tartib

1. Darsdagi serverni `lab-work/srv.py` ga koʻchiring.
2. Alohida terminalda `python3 srv.py` ishga tushiring.
3. `curl` orqali darsdagi qadamlarni oʻting.
4. Kalitning xeshini `proof.txt` ga yozing.
5. `notes.md` da javob bering: server nega kalitni berdi?
