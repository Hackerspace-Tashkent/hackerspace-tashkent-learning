# Практика S0-01: что сервер видит

| # | Требование | Проверяется |
|---|---|---|
| 1 | файл `lab-work/srv.py` существует | да |
| 2 | сервер читает заголовки клиента | да |
| 3 | есть ветка `X-Debug` | да |
| 4 | читает заголовок `X-Access-Key` | да |
| 5 | файл `lab-work/notes.md` существует | да |
| 6 | `proof.txt` содержит хеш найденного ключа | да |
| 7 | **твой сервер** отдаёт секрет и открывает по ключу | живая проверка |

Седьмая — не чтение файла. Проверка поднимает твой сервер, спрашивает
его по HTTP и требует ровно то поведение, ради которого написана тема.

## Порядок

1. Скопируй сервер из урока в `lab-work/srv.py`.
2. Запусти `python3 srv.py` в отдельном терминале.
3. Пройди шаги из урока через `curl`.
4. Запиши хеш ключа в `proof.txt`.
5. Ответь в `notes.md`: почему сервер отдал ключ?

## Проверка

```bash
./check.sh
```
