# Практика S0-02: секрет в коде

| # | Требование | Проверяется |
|---|---|---|
| 1 | репозиторий `lab-work/repo` существует | да |
| 2 | в нём не меньше двух коммитов | да |
| 3 | секрет всё ещё находится в истории | да |
| 4 | `proof.txt` содержит хеш найденного ключа | да |
| 5 | ключа нет в текущем `app.py` | да |
| 6 | файл `.gitignore` существует | да |
| 7 | файл `notes.md` существует | да |

Третья и четвёртая — смысл темы. Ключ берётся **из истории
репозитория**, а не из файла, который перед глазами.

## Порядок

1. `bash setup-repo.sh` — создаёт репозиторий с историей.
2. Найди ключ в истории командами из урока.
3. Проверь, что в текущей версии его нет.
4. Запиши хеш в `proof.txt`.
5. Ответь в `notes.md`: что нужно для настоящего удаления ключа?

./check.sh
