# Практика S0-03: пароли и хеши

| # | Требование | Проверяется |
|---|---|---|
| 1 | файл `brute.py` существует | да |
| 2 | в `crack.txt` пароль, соответствующий искомому хешу | да |
| 3 | файл `proof.txt` существует | да |
| 4 | `salted.py` использует pbkdf2 | да |
| 5 | `salted.py` использует соль | да |
| 6 | в `salted.py` две разные соли | да |
| 7 | запуск даёт **три разных хеша** одного пароля | живая проверка |
| 8 | файл `notes.md` существует | да |

Проверка 7 — не чтение файла. Она запускает твой скрипт и требует, чтобы
для одного пароля получились три разных значения: без соли, с первой и со
второй. Одной соли недостаточно — это проверяется отдельно.

## Порядок

1. `bash setup.sh` — создаёт `hashes.txt` и `target.txt`.
2. Напиши `brute.py`, найди пароль, запиши в `crack.txt`.
3. Запиши хеш в `proof.txt`.
4. Напиши `salted.py` с тремя выводами.
5. Ответь в `notes.md`: зачем туз, если пароль всё равно перебирают?

## Проверка

```bash
./check.sh
```
