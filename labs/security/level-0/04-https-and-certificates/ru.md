# Практика S0-04: HTTPS и сертификаты

| # | Требование | Проверяется |
|---|---|---|
| 1 | файл `cert.pem` существует | да |
| 2 | файл `key.pem` существует | да |
| 3 | сертификат называет `localhost` | да |
| 4 | у сертификата есть начало и конец срока | да |
| 5 | `server.py` использует `ssl` | да |
| 6 | `server.py` загружает сертификат | да |
| 7 | в `proof.txt` отпечаток сертификата | пересчёт |
| 8 | клиент подключается **с проверкой** | живая проверка |
| 9 | клиент подключается **без проверки** и говорит об этом | живая проверка |
| 10 | файл `notes.md` существует | да |

Проверки 8 и 9 — не чтение файла: они **запускают твой сервер** и
подключаются к нему по-настоящему. Нужны оба результата: с проверкой
и без неё. Только второй ничего не доказывает, только первый не
показывает, зачем проверка нужна.

## Порядок

1. Выпусти сертификат командой из урока.
2. Напиши `server.py` и `client.py`.
3. Отпечаток запиши в `proof.txt`.
4. Ответь в `notes.md`: зачем проверка, если шифрование и так работает.

## Проверка

```bash
./check.sh
```
